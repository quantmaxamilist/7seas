# Old → new URLs

| Old (WordPress)                 | New                  | How                                   |
|---------------------------------|----------------------|---------------------------------------|
| `/`                             | `/`                  | same                                  |
| `/gallery/`                     | `/gallery`           | trailing slash dropped (Vercel 308 / `_redirects` 301) |
| `/contact/`                     | `/contact`           | trailing slash dropped                |
| `/feed/`, `/comments/feed/`     | `/`                  | 301                                   |
| `/wp-sitemap*.xml`              | `/sitemap-index.xml` | 301                                   |
| `/author/*`                     | `/`                  | 301                                   |

New pages: `/services/refurbishments`, `/services/extensions`, `/services/loft-conversion`.
